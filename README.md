Week 3 Assignment on Conditions and Loops
Grade Reporter & Bug Hunt

This repository contains my Week 3 Python assignment on conditions and loops.

Files
grade_reporter.py — Uses a for loop and if/elif/else conditions to assign grades, count passes and failures, and calculate the average score.
bug_hunt.py — Finds and fixes three bugs in a while loop program and calculates the sum of the numbers 1 through 5.
Bug Hunt Reflection

The hardest bug to find was the incorrect while loop condition because the program could run without showing an error message. I knew something was wrong because the program did not produce the expected answer of 15. Checking the loop carefully showed that count < 5 stopped the loop before the number 5 could be added.
